`Assets/SimpleVertexBaseColor.lspkg/vertexBaseColorMaterial.mat` comes from CLAD's `SimpleVertexBaseColor.lspkg` package. The locally installed source package matched the upstream package by SHA-256; the material file matched the package entry byte-for-byte. Lens Studio imported and converted the accompanying source shader graph to `vertexBaseColorShader.graphShader` in this project. Copyright 2026 Specs Inc. The upstream repository's license identifies its contents as Apache License 2.0 except where otherwise noted; a copy is in [CLAD-APACHE-2.0-LICENSE.txt](CLAD-APACHE-2.0-LICENSE.txt).

Source: [lens-studio-devs/ls-extensions](https://github.com/lens-studio-devs/ls-extensions), `plugins/ls-clad/skills/mesh-builder-scripting/resources/SimpleVertexBaseColor.lspkg`.
