# Pocket Curator

Explore a miniature garden museum in Lens Studio's laptop preview for SPECS 27. Choose a flower, bee, or mushroom to reveal a short nature fact and animate the exhibit. The museum uses a virtual shelf that you can look around in the preview.

## Open the project

1. Install [Lens Studio 5.23.2](https://lensstudio.com/download/v5-23-2), the version used to author the project and exercise its three choices in Preview.
2. Clone this repository or use **Code → Download ZIP** on GitHub and extract the entire archive. Keep `Pocket-Curator.esproj`, `Assets/`, and `Packages/` together. Open `Pocket-Curator.esproj` in Lens Studio.
3. Set the Preview panel to an interactive SPECS preview. You should see the shelf and the guide near the initial view. Hover over a guide button and click. **Flower** sways, **Bee** hovers and flaps, and **Mushroom** pulses. Choose a second exhibit to switch the fact and motion.

The laptop workflow requires no glasses. The shelf uses a fixed virtual placement and has no physical tabletop detection. The original build recorded a clean Lens Studio compile and runtime log. A clean archive reopen, newer Lens Studio versions, LEAF scenarios, and physical-device tracking, comfort, and audio quality remain unverified.
